# Векторные элементы CAMP — первый проход

Настоящие SVG, без image, встроенных PNG или трассировки пикселей. Каждый файл самостоятельный; внутри именованные группы для дальнейшей композиции и анимации.

- campfire.svg: glow, ground, logs, outer-flames, inner-flames, flame-core, stones, embers.
- lantern.svg: glow, handle, body.
- forest-lake.svg: sky-layer, stars, moon, mountains, distant-pines, lake, cabins, shore, foreground-pines, framing-branches.

Это первые элементы ручной перерисовки, а не законченная копия референса. Персонажи, гитара, шатёр, веранда и телефон ещё не отрисованы. На главную эти иллюстрации пока не подставлены: сначала проверяется направление рисунка.
