# CAMP campfire ambience

`campfire.wav` is an original procedural recording authored for this project, not a stock download. Noise filtering, short crackle envelopes, wood pops and a loop crossfade are generated by `tools/generate-fire-audio.py`.

35 seconds, 22050 Hz, stereo PCM16. No external samples, attribution or stock licence dependencies. Generated project audio is released under CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/

Playback starts only after a user action. The volume is local to the device. No microphone access is required.
